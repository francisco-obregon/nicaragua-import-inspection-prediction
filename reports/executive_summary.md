# Executive Summary

## Objective

Build a machine learning model to predict which import shipments should be inspected using historical customs data.

## Key Results

* ~90% overall accuracy
* ~78% recall for inspection detection (priority metric)

## Business Impact

The model helps customs authorities prioritize high-risk shipments, reducing the probability of missing critical inspections while optimizing operational resources.

## Key Insight

Due to class imbalance, prioritizing recall for inspection cases significantly improves risk detection, even at the cost of some false positives.

## Recommendation

Deploy the model as a decision-support tool to assist customs officers in identifying high-risk shipments and improving inspection efficiency.
